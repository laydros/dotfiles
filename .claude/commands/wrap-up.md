End-of-session wrap-up: update memory and journal before Jason closes out.

Be selective. The bar for saving is high — most sessions produce nothing worth keeping. A short "nothing new this session" is a perfectly good outcome.

## Memory

The four types, the de-duplication rule, and the list of what not to save are built-in defaults. Follow them as written; they aren't repeated here.

Two things they don't cover:

- If you're unsure whether something is worth keeping, it isn't.
- Write the saves yourself. Don't ask permission for bookkeeping — report what you saved after the fact, one line each.

## Journal

If the `mcp__private-journal__process_thoughts` tool is available, decide yourself whether this session produced reasoning worth finding again in three months — architectural reasoning, surprises, why a decision went the way it did. If it didn't, write nothing. Never a session recap. If the tool isn't available, skip silently.

A correction that should change future behavior goes in memory or CLAUDE.md, not here. The journal is where such a note goes to die.

## Output

Keep it terse. List what you saved to memory and journal, or "nothing worth keeping". Don't write a session summary.
